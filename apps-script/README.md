# Обработчик RSVP → Google Таблица

Обработчик пишет ответы в отдельный лист **«RSVP сайта»** в [существующей таблице](https://docs.google.com/spreadsheets/d/11cilhydWbMj9I30tHIC-c5-EH6p1COI1eCYzGjP_SYU/edit). Лист Google Формы и старые ответы не меняются. Ответы сайта не будут отображаться на вкладке «Ответы» Google Формы — смотрите лист «RSVP сайта».

## Однократный запуск владельцем таблицы

1. Войдите в Google под аккаунтом с правом редактирования таблицы и откройте https://script.google.com/home/start.
2. Назовите проект **«Свадьба — RSVP сайта»**.
3. Замените всё содержимое файла `Код.gs` / `Code.gs` кодом из `apps-script/Code.gs` этого проекта и сохраните. ID таблицы уже указан в коде.
4. Нажмите **Развернуть → Новое развертывание**. Тип: **Веб-приложение**.
5. **Запуск от имени: Я** (владелец). **У кого есть доступ: Все / Anyone** — в том числе неавторизованные посетители. Не выбирайте «Все пользователи с аккаунтом Google».
6. Нажмите **Развернуть**, подтвердите запрошенный доступ к Google Таблицам для вашего собственного проекта. Учётные данные вводите только на страницах Google, не в чате и не в файлах проекта.
7. Скопируйте **URL веб-приложения** вида `https://script.google.com/macros/s/…/exec`. Нужен именно `/exec`, не `/dev`, не адрес редактора и не ID проекта.
8. Откройте URL в приватном окне, без входа в Google. Должен отобразиться JSON `{"ok":true,"service":"wedding-rsvp","version":1}`, а не страница входа. Это проверка доступности; она ещё не проверяет запись ответа.
9. Передайте этот URL для подключения сайта. Он публичный, не содержит пароль или OAuth-токен.

## Подключение к сайту

- Локально: создайте `.env.local`, добавьте `VITE_RSVP_ENDPOINT=ваш_URL_с_/exec`, перезапустите `npm.cmd run dev`.
- GitHub: **Settings → Secrets and variables → Actions → Variables → New repository variable**, имя `VITE_RSVP_ENDPOINT`, значение — тот же URL. Затем повторно запустите workflow публикации. URL попадёт в публичный JS — это нормально. Никаких Google-токенов в `VITE_*` быть не должно.
- Без endpoint локальная разработка остаётся демо. В production кастомная анкета не отправляется; доступна резервная ссылка на прежнюю Google Форму. Ложного подтверждения и записи только в браузер в production нет.

## Проверка

1. Отправьте тестовый ответ с сайта: имя, присутствие, 2 гостя, аллергия, трансфер и комментарий.
2. Убедитесь, что в таблице появился лист «RSVP сайта» и строка со всеми полями. Только после записи и `SpreadsheetApp.flush()` обработчик возвращает `ok: true` и ID ответа; сайт проверяет оба значения.
3. Проверьте отказ от участия: количество гостей должно быть 0, трансфер — «Нет».
4. При ошибке данные не очищаются. Повторная отправка неизменённой анкеты использует прежний ID: если запись уже произошла, дубликат не создаётся. После перезагрузки страницы это свойство не гарантируется.
5. Проверьте работу в приватном окне и на телефоне. Если браузер не даёт прочитать ответ сервиса (CORS, блокировщик, сеть), успех не показывается. Не используйте `no-cors` как «исправление» — он скроет подтверждение сохранения.

Обработчик принимает простой POST с JSON-телом и `Content-Type: text/plain`, чтобы избежать неподдерживаемого Apps Script preflight OPTIONS. Ответ JSON выдаёт ContentService; браузер следует редиректу Google. Реальный браузерный POST необходимо проверить после развёртывания: локальные тесты не проверяют инфраструктуру Google и её CORS-заголовки.

## Обновления и ограничения

При изменении `Code.gs`: **Развернуть → Управление развертываниями → Изменить → Версия: Новая версия → Развернуть**. При обновлении существующего развертывания URL не меняется. Простое сохранение кода не обновляет `/exec`.

Endpoint доступен всем для добавления ответов, но не для чтения таблицы. Не публикуйте саму таблицу. Обработчик проверяет длины полей и значения, защищает текст от формул, использует блокировку и ID для повторов. Это не защита от целевого спама: публичный адрес можно вызвать вне сайта. Для небольшой гостевой анкеты этого достаточно; при злоупотреблении потребуется дополнительная серверная защита. Квоты Google Apps Script также действуют.
