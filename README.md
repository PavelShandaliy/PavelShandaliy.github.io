# Свадебный сайт Павла и Виктории

Адаптивный сайт-приглашение на React + Vite. Главная страница включает историю пары, детали, тайминг, фотографии, обратный отсчёт и RSVP. Отдельная страница `admin.html` показывает ответы, сохранённые в текущем браузере, и позволяет скачать CSV.

## Запустить локально

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`). В PowerShell с ограничением запуска скриптов используйте `npm.cmd install`, `npm.cmd run dev` и т. п. Для production-сборки: `npm run build`; проверить её можно через `npm run preview`.

## RSVP: анкета в дизайне сайта → Google Таблица

Возвращена собственная React-анкета в цветах сайта. Ответы отправляются в Google Таблицу через Google Apps Script; Google Форма больше не встраивается.

**Обработчик развёрнут и подключён:** адрес задан в GitHub Actions variable `VITE_RSVP_ENDPOINT` и локальном `.env.local` (не хранится в Git). Проверены доступ без входа в Google и подтверждение реального POST. Код: `apps-script/Code.gs`. Инструкция для повторного развёртывания: [apps-script/README.md](apps-script/README.md).

- [Таблица ответов](https://docs.google.com/spreadsheets/d/11cilhydWbMj9I30tHIC-c5-EH6p1COI1eCYzGjP_SYU/edit): новые ответы сайта находятся на отдельном листе **«RSVP сайта»**. Старый лист Google Формы не меняется.
- [Прежняя Google Форма](https://docs.google.com/forms/d/e/1FAIpQLSfksHDpRHD6ThPH03NCvT8qr8J-mqjbaEdSbpQJXybDsJaGCg/viewform) остаётся резервным способом ответа до подключения обработчика.

В `.env.local` для разработки или Actions variable для публикации задайте `VITE_RSVP_ENDPOINT=https://script.google.com/macros/s/ВАШ_ID/exec`. Это публичная ссылка, не секрет. Не помещайте пароли и OAuth-токены в `VITE_*`.

Без endpoint `npm run dev` работает в демо-режиме (localStorage); в production отправка отключена и предлагается резервная Google Форма. Production не сохраняет ответы только в браузере. `admin.html` показывает исключительно локальные демо-ответы, не защищён паролем и не читает Google Таблицу.

Успех показывается только после читаемого JSON-подтверждения `ok: true` с ID именно этого ответа. При таймауте / ошибке введённые данные сохраняются; повтор без изменения полей в той же открытой анкете не создаёт дубликат. Ответы сайта не попадают в статистику Google Формы, смотрите лист «RSVP сайта».

Проверки логики отправки, ошибок и обработчика: `npm.cmd test`. Проверка полной интеграции с Google возможна только после развёртывания и подключения URL.

## Бесплатный деплой на GitHub Pages

Репозиторий `pavikhan/pavikhan.github.io` соответствует адресу сайта **https://pavikhan.github.io/**.

1. Загрузите файлы проекта в ветку `main`, включая `.github/workflows/deploy.yml`. Не загружайте `node_modules`, `dist` и `.env.local`.
2. В репозитории откройте **Settings → Pages** и в **Build and deployment → Source** выберите **GitHub Actions**.
3. Отправьте изменения в `main`. Workflow автоматически соберёт сайт и опубликует папку `dist`; результат и адрес деплоя появятся в **Actions** и **Settings → Pages**.
4. Для собственной анкеты добавьте Actions variable `VITE_RSVP_ENDPOINT` (см. раздел RSVP) и повторно запустите workflow. После публикации отправьте тестовый ответ и проверьте лист «RSVP сайта». Пока обработчик не подключён, остаётся резервная ссылка на Google Форму.

`base: './'` подходит для этого репозитория пользовательского сайта.

## Дизайн и цветовые варианты

В текущей версии использована палитра **«Байкал и хвоя»**: хвойный зелёный `#173a32`, тёплый айвори `#f7f5ed`, приглушённое золото `#d7b77a` и шалфейные оттенки. Она поддерживает спокойный элегантный стиль с засечковыми заголовками.

Ещё два варианта, если захотите сменить настроение: **«Байкальский туман»** — глубокий сине-серый, ледяной голубой, молочный и серебро; **«Степной закат»** — тёплый песочный, терракота, тёмный шоколад и сливочный. Основные цвета собраны в CSS-переменных в начале `src/style.css`.

## Что проверить / заменить перед публикацией

- **Место и карта:** метка Яндекс Карт использует координаты `51.906710, 104.805699` (широта, долгота). Проверьте, что точка совпадает с площадкой и подъездом; отображаемый адрес и трансфер также нужно подтвердить.
- **Фото:** используются `1.jpg` в первом экране, `2.jpg` в разделе истории и `10.jpg`–`17.jpg` в галерее из `public/photos/`.
- **Подписи к фотографиям:** проверьте, что подписи галереи соответствуют выбранным снимкам.
- **Превью в мессенджерах:** canonical URL и абсолютный `og:image` на `https://pavikhan.github.io/photos/1.jpg` уже настроены в `index.html`.
- **RSVP:** проверьте приём ответов после публикации. Реальные ответы сайта смотрите на листе «RSVP сайта» Google Таблицы, а не в `admin.html`.
- **Подарки:** ссылка на реестр не была предоставлена. Вставьте её в `GIFT_REGISTRY_URL` в начале `src/main.jsx`; блок появится автоматически.
- **Дресс-код / программа:** тексты составлены по ТЗ; проверьте формулировки и расписание перед рассылкой гостям.

## Основные файлы

- `src/main.jsx` — сайт и RSVP-форма;
- `src/rsvp.js` — отправка с проверкой подтверждения;
- `apps-script/Code.gs` — обработчик записи в Google Таблицу;
- `src/admin.jsx` — локальный список ответов / CSV для тестирования;
- `src/style.css` — оформление и адаптивность;
- `index.html`, `admin.html` — точки входа и метаданные;
- `public/photos/` — фотографии сайта;
- `.github/workflows/deploy.yml` — автоматическая публикация на GitHub Pages.
